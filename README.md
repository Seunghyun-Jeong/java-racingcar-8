# java-racingcar-precourse

## 기능

- **자동차 및 경주 설정 :**
  - 경주할 각 자동차에 이름을 부여, 이름은 쉼표(",")를 기준으로 구분 (자동차 이름은 5자 이하만 가능)
  - 사용자는 몇 번의 이동을 시도할 것인지 입력 
  - 사용자가 잘못된 값을 입력할 경우 에러메시지 출력
  

- **전진 조건 :**
  - 0~9 사이의 무작위 값을 구함
  - 무작위 값이 4 이상일 경우 자동차는 한 칸 전진, 3 이하일 경우 멈춤


- **게임 실행 및 결과 :**
  - 전진하는 자동차를 출력할 때, 자동차 이름과 현재까지의 전진 거리를 하이픈("-")으로 표시하여 함께 출력
  - 게임 완료 후, 가장 멀리 전진한 자동차를 우승자로 선정
  - 우승자가 여러 명일 경우, 쉼표(",")를 이용하여 이름을 구분하여 출력

---

## 사용 방법

1. 프로그램을 실행하면 경주할 자동차 이름을 쉼표로 구분하여 입력
2. 시도할 횟수를 숫자로 입력

---

## 입력 예시

- 경주할 자동차 이름
  - pobi,woni,jun


- 시도할 횟수
  - 5
